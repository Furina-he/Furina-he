# Product

## Platform

web (GitHub Profile README)

## Users

Developers exploring local-first AI agent guardrails (`CloudLink`), resident desktop AI companions (`OpenPet`), agent-ready GitHub profile themes (`GitSkins`), and 3D interactive circuit simulation (`Virtual`).

## Product Purpose

Powers the public GitHub profile for `Furina-he` (`NeverGiveUp`) with a unified Swiss-Bauhaus pixel poster visual language that stays crisp, calm, and legible in both GitHub Light and Dark modes.

## Capabilities and Constraints

- Repository-hosted Light/Dark SVG suite (`assets/`) generated deterministically via `scripts/generate_assets.py` with `0px` sharp geometry, 9-row bold pixel display glyphs, orthogonal pixel weaves, and a gently blinking 28x28 pixel portrait.
- Flush `2x2` clickable poster cards for `CloudLink`, `OpenPet`, `GitSkins`, and `Virtual`, accompanied by live site links (`cloudlink.blessc.com`, `openpet.myfurina.top`, `gitskins.blessc.com`) and a daily-updated GitHub contribution snake workflow.
